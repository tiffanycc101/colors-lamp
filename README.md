# COLORS LAMP Application

## Description

COLORS is a web application created for COP4331 using the LAMP stack. Users can log in, add colors, and search colors associated with their account.

## Technologies Used

- Linux
- Apache
- MySQL
- PHP
- HTML
- CSS
- JavaScript

## Setup

1. Configure a LAMP server.
2. Create the COP4331 MySQL database and required tables.
3. Configure the database connection on the server.
4. Place the project files in the Apache web directory.

Database credentials are not included in this repository.

## Running the Application

Open the server's IP address or domain in a web browser. The application starts from index.html.

## Limitations

This application was created for educational purposes and is not intended for production use.
